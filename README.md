# 🔥 熱愛バレた件

アイドル・ひろととの熱愛がスクープされた日を体験する、スマホ風SNSゲーム（単一HTML＋画像アセット、フレームワークなし）。

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/hiroto-netsuai-bareta/

## あらすじ / 遊び方
1. ホーム画面で約3秒待つと、ニュース速報プッシュが来る。タップすると物語スタート。
2. X：トレンド1位 #大翔熱愛、メンションが流れ続ける。フォロワーは 189 → 38,427 に爆増。
3. Instagram：なおのフォロワーは 342 → 52,814 に。コメントとDMリクエストが殺到。ひろと本人の垢（193.hiroto_jixiang）も見られる。
4. ニュース：速報記事 → 事務所コメント → 「匂わせ」掘り起こしと続報が増える。
5. LINE：ひろとから短くて素直な関西弁の連絡が来る。返信は3択、「声、聞きたい」を選ぶと通話画面にもなる。
6. 最後の選択でエンディングが3つに分岐する。

## 土台（元ネタ）について
- iPhone枠の考え方は、GitHubのMITライセンス系iOSモック **c2prods/Project-Tyson**（"faking the UI of iOS in HTML, CSS and Javascript"）等の構造を参考に、本作向けに自作した。
- アプリ群（ホーム画面＋SNS＋LINE＋バッジ＋プッシュ通知）の実装方式は、自作ゲーム『キープ管理中！』（ https://github.com/v5m44g26fb-sudo/keep-kanri-game ）の方式を流用。
- 調査メモ：本格的なiPhoneポートフォリオ系（例：shivang1141/iphone-portfolio、Vite+TS）や単一ファイル系（benja364/IPHONE-13-virtual）はライセンス表記がなく流用しづらく、重さ・素性からも不採用とした。

## v2改修（2026-11-02）
- ロック画面（通知スタック付き、タップで解除）を追加。速報プッシュは解除後に届く。
- 着信画面（応答／拒否つき）。拒否するとLINEでフォローが来る。
- LINEに自由入力を追加：好きな文を送ると、ひろとが短い関西弁で自動返信する（キーワード反応あり）。
- X・Instagramで「いいね」が押せる。メンション／コメントはその後もランダム生成で増え続ける。
- ひろとのストーリー（炎上前／炎上後で内容が変わる）。
- エンディング後に「翌朝編」：ひろとの公式コメント投稿（長文・丁寧バージョン）＋分岐別の後日談。
- ひろとの画像の一部は、本人のInstagram（@193.hiroto_jixiang）の実際の投稿から取得した写真と実キャプション（「食べまくってる🍚 いつもコーラ」等）を使用。フォロワー数も実数（約8.1万）に寄せた。
- なおのアカウント画像は、本人の希望により初期アイコン（人型シルエット）を使用。本人の顔写真は使っていない。
